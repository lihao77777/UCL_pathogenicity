# UCL Pathogenicity Analysis Utility
This repository contains R scripts developed during my computational genetics research at UCL for analysing and visualising pathogenicity-related results from rare-variant analyses.  

The workflow is designed to run in a cluster environment and can take outputs from scoreassoc or tabular variant-level data as input. It integrates pathogenicity scores and generates summary plots and visualisations to support variant interpretation.  

Key features
- Rare-variant pathogenicity analysis
- Integration of variant-level pathogenicity scores
- Automated plotting and visualisation
- R-based workflow designed for HPC/cluster environments
